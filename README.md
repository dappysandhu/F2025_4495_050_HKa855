## Project Description
The **Community Emergency Response App (CERA)** is a mobile application built with **React Native** to assist communities in preparing for and responding to emergencies.

---

## Tech Stack
- **React Native (Expo or CLI)**  
- **JavaScript/TypeScript**  
- **Firebase / Firestore (if used for backend)**  
- **Node.js & npm/yarn** for dependency management  

---

## Prerequisites
Make sure you have installed:
- [Node.js](https://nodejs.org/) (LTS recommended)  
- [npm](https://www.npmjs.com/) or [Yarn](https://yarnpkg.com/)  
- [Expo CLI](https://docs.expo.dev/get-started/installation/) (if using Expo workflow)  
- Android Studio / Xcode (for Android/iOS simulators)  

---

## Installation & Setup
```bash
# Clone repo
git clone https://github.com/YourGitHubUsername/F2025_4495_050_HKa855.git
cd F2025_4495_050_HKa855/Implementation

# Install dependencies
npm install
# or
yarn install

# Run the app
npm start
# or
yarn start
```
